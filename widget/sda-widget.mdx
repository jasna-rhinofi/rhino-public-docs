## Embedding the Rhino.fi SDA Widget (iframe)

You can embed the Rhino.fi SDA Widget into any site with a simple `<iframe>`. It provides a complete UI for creating Smart Deposit Addresses and settling deposits to a destination address, with no installation or bundling.

### ⚡ Quick Start

You can design your widget visually in our playground, **or** use the example code below directly.

<Card title="Customize Your Theme" icon="wrench" href="https://playground.rhino.fi/">
  Use our playground to visually design and preview your widget, then copy the embed code.
</Card>

Paste this HTML where you want the widget to appear:

```html
<iframe
  src="https://address.rhino.fi/?apiKey=YOUR_PUBLIC_API_KEY&chainIn=ETHEREUM&chainOut=BASE&token=USDC&recipient=0xYOUR_RECIPIENT_ADDRESS"
  style="width: 400px; height: 581px; max-width: 100%; border: none"
  scrolling="no"
/>
```

Replace `YOUR_PUBLIC_API_KEY` with your Rhino.fi **public** API key, and `0xYOUR_RECIPIENT_ADDRESS` with the address that should receive the funds.

<Warning>
  Always use a **public** key in the widget. The key is part of the iframe URL, so anyone visiting your page can see it. Never use a secret key here: it gives access to your full transaction history. See [Authentication](/api-integration/authentication#choose-a-key-type).
</Warning>

Unlike the [bridge widget](/widget/widget), the SDA widget has no default configuration: `chainIn`, `chainOut`, `token` and `recipient` are all required.

## Customization

You can customize the widget's appearance and default values with URL query parameters:

| Query Param       | Required | Description                             | Example                          |
| ----------------- | :------: | --------------------------------------- | :------------------------------: |
| <b> apiKey</b> | ✅ | Your **public** API key | `apiKey=YOUR_PUBLIC_API_KEY` |
| <b> chainIn</b>   | ✅       | Source chain                            | `chainIn=ETHEREUM`               |
| <b> chainOut</b>  | ✅       | Destination chain                       | `chainOut=BASE`                  |
| <b> token</b>     | ✅       | Source token                            | `token=USDT`                     |
| <b> recipient</b> | ✅ | Destination (recipient) address | `recipient=0xYOUR_RECIPIENT_ADDRESS` |
| <b> tokenOut</b>  |          | Destination token                       | `tokenOut=USDC`                  |
| <b> amount</b>    |          | Pre-fills the amount in the deposit QR code | `amount=10`                  |
| <b> mode</b>      |          | Widget mode (light or dark)             | `mode=dark`                      |
| <b> theme</b>     |          | Theme configuration in JSON             | `theme={...}` (URL-encoded JSON) |

## 🎨 Theming

You can customize how the widget looks by passing a `theme` query param as URL-encoded JSON.

Supported theme properties:

```ts
type WidgetTheme = {
  colors?: {
    primary?: string               // Primary color / CTA color
    primaryLight?: string          // Light variation of the primary color
    secondary?: string             // Secondary color
    widgetBackground?: string      // Background of the full widget
    select?: string                // Background of input/select fields
    textPrimary?: string           // Default widget text color
    textSecondary?: string         // Secondary or muted text
    textPrimaryCta?: string        // Text color for primary buttons
    textSecondaryCta?: string      // Text color for secondary buttons
    stroke?: string                // Border/stroke color
  }
  radius?: {
    widget?: string                // Border radius for main widget container
    actionElements?: string        // Radius for buttons and actions
    tokenSelect?: string           // Radius for token select
  }
  tokenInputStroke?: boolean       // Whether to show stroke or fill on token input
  googleFontFamily?: string        // Google Font family name to load and apply
}
```

Example with a custom theme:

```html
<iframe
  src="https://address.rhino.fi/?apiKey=YOUR_PUBLIC_API_KEY&chainIn=ETHEREUM&chainOut=BASE&token=USDC&recipient=0xYOUR_RECIPIENT_ADDRESS&mode=light&theme=%7B%22colors%22%3A%7B%22primary%22%3A%22red%22%7D%7D"
  style="width: 400px; height: 581px; max-width: 100%; border: none"
  scrolling="no"
/>
```
