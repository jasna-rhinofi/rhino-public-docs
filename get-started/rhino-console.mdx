## What the Console covers

| Section | Description |
| --- | --- |
| **Transaction history** | Full history of all bridges, SDA deposits and settlement events for your account |
| **Analytics** | Volume, success rate, fee totals and per-chain breakdown |
| **API key management** | Create, rotate and revoke API keys |
| **Integrate** | Register and manage your webhook URL under **Integrate → Webhooks** |
| **Settings** | Manage team members and access levels, and see your **Usage**, including SDA usage against your limits |

## API keys

API keys are created and managed in the Console. Each key is scoped to your account. There are two types:

| Key type | Use |
| --- | --- |
| **Secret key** (prefixed `SECRET_`) | Full access, including your transaction history and SDA search. Use it only in server-side code. |
| **Public key** | Quotes, bridge execution and public reads. Safe to use in browser and mobile apps. |

Store secret keys securely, for example in a secrets manager, and never expose them in client-side code. See [Authentication](/api-integration/authentication) for which key to use where.

## Webhooks

Register one webhook URL per project under **Integrate → Webhooks**. Enter your base URL only: Rhino.fi adds `/rhinofi-event` to it. See [Track transactions](/api-integration/status-history#receive-webhooks) for the events you receive.

## Access

The Console requires you to sign in with a Google Workspace account. You can invite teammates to help manage your project.
