## Contract overview

The bridge contract exposes two functions for deposits:

```solidity
/**
* Deposit ERC20 tokens to the contract address with a commitment ID
*/
function depositWithId(
  address token,
  uint256 amount,
  uint256 commitmentId
) public;

/**
* Deposit native chain currency into contract address with a commitment ID
*/
function depositNativeWithId(
  uint256 commitmentId
) external payable;
```

The `commitmentId` is the [quote ID](/api-integration/core-concepts#the-quote-id) from your committed quote. The API returns it as a hex string, so convert it to a `uint256` before calling the contract: `BigInt("0x" + quoteId)`.

<Warning>
  Don't use these functions for same-chain swaps. Those use a different contract and prepared calldata. See [Same-chain swaps](/api-integration/bridge#same-chain-swaps).
</Warning>

## Setup

This example uses [ethers v6](https://docs.ethers.org/v6/), but you can use any EVM library.

<CodeGroup>

```bash npm
npm install ethers
```

```bash yarn
yarn add ethers
```
</CodeGroup>

## Call the contract

To send a deposit, call `depositWithId` for ERC-20 tokens or `depositNativeWithId` for the chain's native token:

```javascript
import { Contract, JsonRpcProvider, Wallet, parseUnits } from 'ethers'
import { rhinoFetch } from './rhino.js' // helper from the Authentication guide
import erc20Abi from './erc20Abi.json'
import bridgeAbi from './bridgeAbi.json'

export async function callEvmBridgeContract({ amount, chain, token, quoteId }) {
  const configs = await rhinoFetch('/bridge/configs', { auth: false })
  const chainConfig = configs[chain]

  // Replace with your own signer, such as a custody provider or MPC wallet
  const wallet = new Wallet(process.env.EVM_PRIVATE_KEY, new JsonRpcProvider(chainConfig.rpc))

  const bridgeContract = new Contract(chainConfig.contractAddress, bridgeAbi, wallet)
  const commitmentId = BigInt(`0x${quoteId}`)

  // Native token: send the amount as the transaction value
  if (token === chainConfig.nativeTokenName) {
    const value = parseUnits(amount, chainConfig.nativeTokenDecimals)
    const tx = await bridgeContract.depositNativeWithId(commitmentId, { value })
    return tx.wait()
  }

  // ERC-20 token: convert to base units exactly, never with floating-point math
  const tokenConfig = chainConfig.tokens[token]
  const tokenAmount = parseUnits(amount, tokenConfig.decimals)

  // Approve the bridge contract if the current allowance is too low
  const erc20Contract = new Contract(tokenConfig.address, erc20Abi, wallet)
  const allowance = await erc20Contract.allowance(await wallet.getAddress(), chainConfig.contractAddress)
  if (allowance < tokenAmount) {
    const approveTx = await erc20Contract.approve(chainConfig.contractAddress, tokenAmount)
    await approveTx.wait()
  }

  const tx = await bridgeContract.depositWithId(tokenConfig.address, tokenAmount, commitmentId)
  return tx.wait()
}
```

`amount` is the quote's `payAmount`: a decimal string in whole token units, such as `"250"`. See [Amounts](/api-integration/core-concepts#amounts).

Once the deposit is confirmed, track the transfer with webhooks or the status endpoint. See [Track transactions](/api-integration/status-history).
