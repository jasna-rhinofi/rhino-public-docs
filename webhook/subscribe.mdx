## Using the Rhino.fi Console

In the Rhino.fi Console, open **Integrate** in the navigation bar. Under **Webhooks**, you can add a new webhook or view an existing one.

To add a webhook, enter your webhook URL.

<Warning>
  Don't include the `/rhinofi-event` suffix. Rhino.fi adds it for you. For example, if you enter `https://my-server.com/prefix`, Rhino.fi calls `https://my-server.com/prefix/rhinofi-event`.
</Warning>

All webhook events for the project are sent to this URL. See the [events list](/webhook/events-list) for every event type.

## Setting a URL in an API request

To send events for a specific transfer or Smart Deposit Address to a different URL, pass it in the `webhookUrl` field of the request. It overrides your project webhook for that transfer or address only.

- [`POST /bridge/quote/bridge-swap/user`](/api-reference/bridge/quote/generate-a-bridgebridge+swap-quote): for bridge and bridge+swap activity
- [`POST /sda/deposit-addresses`](/api-reference/sda/depositaddresses/generate-a-new-smart-deposit-address): for a Smart Deposit Address and all its deposits
