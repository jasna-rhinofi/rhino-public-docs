The Rhino.fi SDK is a JavaScript/TypeScript client for the Rhino.fi Stablecoin Activation Stack. It handles authentication, config fetching, quote generation and transaction execution, so you can bridge assets with a few lines of code. For other languages, use the [REST API](/api-integration/introduction) directly.

## Install the package

<CodeGroup>

```bash npm
npm install @rhino.fi/sdk
```

```bash yarn
yarn add @rhino.fi/sdk
```

```bash pnpm
pnpm install @rhino.fi/sdk
```

```bash bun
bun install @rhino.fi/sdk
```

</CodeGroup>

## Initialize the SDK

```typescript
import { RhinoSdk } from '@rhino.fi/sdk'

export const rhinoSdk = RhinoSdk({
  apiKey: process.env.RHINO_API_KEY,
})
```

<Warning>
  Use a **public** key if the SDK runs in a browser or mobile app. Use a **secret** key only in server-side code, where it can't be exposed. See [Authentication](/api-integration/authentication#choose-a-key-type) for what each key type can access.
</Warning>

## Make a bridge transfer

```typescript
import { SupportedChains, SupportedTokens } from '@rhino.fi/sdk'
import { getEvmChainAdapterFromPrivateKey } from '@rhino.fi/sdk/adapters/evm'
import { rhinoSdk } from './rhino-sdk'

const bridgeResult = await rhinoSdk.bridge({
  type: 'bridge',
  amount: '100',
  token: SupportedTokens.USDT,
  chainIn: SupportedChains.ARBITRUM_ONE,
  chainOut: SupportedChains.SOLANA,
  depositor: 'DEPOSITOR_ADDRESS',
  recipient: 'RECIPIENT_ADDRESS',
  mode: 'receive',
  gasBoost: {
    amountNative: '4',
  },
}, {
  getChainAdapter: chainConfig =>
    getEvmChainAdapterFromPrivateKey(process.env.EVM_PRIVATE_KEY, chainConfig),
  hooks: {
    checkQuote: quote => quote.fees.feeUsd < 5,
    onBridgeStatusChange: status => console.log('Bridge status changed', status),
  },
})

if (bridgeResult.data) {
  console.log('Bridge successful', bridgeResult.data.withdrawTxHash)
} else {
  console.log('Bridge error', bridgeResult.error)
}
```

This bridges 100 USDT from Arbitrum to Solana, and also delivers 4 SOL to the recipient address with [Gas Boost](/api-integration/bridge#gas-boost). With `mode: 'receive'`, the recipient gets exactly 100 USDT and fees are added on top (see [Choose a mode](/api-integration/bridge#choose-a-mode)). The `checkQuote` hook cancels the transfer if fees would be more than \$5.

In production, use your own signer, such as a custody provider or MPC wallet, instead of a raw private key.

## Create a Smart Deposit Address

Smart Deposit Addresses let users send funds with a simple token transfer, with no contract interaction.

```typescript
import { rhinoSdk } from './rhino-sdk'

const sda = await rhinoSdk.api.depositAddresses.create({
  depositChains: ['ETHEREUM', 'ARBITRUM', 'BASE'],
  destinationChain: 'BASE',
  destinationAddress: '0x123...',
})
// Result:
// {
//   depositAddress: '0x457...',
//   depositChain: 'ETHEREUM',
//   destinationChain: 'BASE',
//   destinationAddress: '0x123...',
//   supportedTokens: [{ symbol: 'USDT', address: '0x789...' }],
//   isActive: true,
// }
```

Once it's created, anyone can send supported tokens to the deposit address, and the funds are settled to the destination automatically.

```typescript
import { rhinoSdk } from './rhino-sdk'

// Check the status of an existing SDA
const status = await rhinoSdk.api.depositAddresses.getStatus({
  depositAddress: '0x457...',
  depositChain: 'ETHEREUM',
})
```

We recommend creating SDAs on every available EVM chain at once, so funds sent on the wrong chain are still detected automatically.

For more details, see the [SDK SDA reference](/sdk/smart-deposits) or the [Smart Deposit Addresses guide](/api-integration/smart-deposits).
