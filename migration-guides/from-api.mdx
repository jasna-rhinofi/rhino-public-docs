## Use the bridge functions

For most use cases, you can replace your manual API and blockchain calls with the [`bridge`](/sdk/bridge-functions/bridge) or [`prepareBridge`](/sdk/bridge-functions/prepare-bridge) function and the included [chain adapters](/sdk/chain-adapters/overview). These handle all the details of the Rhino.fi API and smart contracts for you.

If your use case isn't covered by them, read on to learn how to use the SDK's underlying building blocks directly.

If the included chain adapters don't cover your use case, you can [implement a custom chain adapter](/sdk/chain-adapters/custom-chain-adapters) and use it with `bridge` or `prepareBridge`.

## Use the SDK API wrappers

If you need to stay in control of every API call, you can still replace your manual calls with the SDK's wrappers and write much less code:

```typescript
// Manual API call
const response = await fetch('https://api.rhino.fi/bridge/quote/bridge-swap/user', {
  method: 'POST',
  headers: {
    'content-type': 'application/json',
    'authorization': jwt,
  },
  body: JSON.stringify(quoteArgs),
})
const quote = await response.json()

// SDK replacement
const result = await rhinoSdk.api.bridge.getSwapUserQuote(quoteArgs)
```

Under `api.bridge` and `api.config`, the SDK has an equivalent for every API call you may have used. The parameters are mostly the same, with small convenience changes in some wrappers. The SDK also handles authentication, so you don't need to manage JWTs yourself.

## Use the SDK chain adapters

If you want direct control of the blockchain interactions, you can use the included chain adapters on their own:

```typescript
// Set up the chain adapter. This can be any of the included ones.
const evmChainAdapter = getEvmChainAdapterFromPrivateKey(
  process.env.EVM_PRIVATE_KEY,
  chainConfig,
)

// Check whether a token approval is needed. You can skip this on chains
// without token approvals, such as Solana.
const approvalAmount = await evmChainAdapter.getApprovalAmount(depositAmount, walletAddress, tokenConfig)
if (approvalAmount) {
  // Set up the token approval if needed
  await evmChainAdapter.handleTokenApproval(approvalAmount, tokenConfig)
}

// Send the funds to the bridge contract. commitmentId is the quote ID of the
// committed quote.
const { depositTxHash } = await evmChainAdapter.handleDeposit({
  tokenConfig,
  depositAmount,
  commitmentId,
})
```

Once the deposit succeeds, track the transfer through the API as usual. See [Track transactions](/api-integration/status-history).
